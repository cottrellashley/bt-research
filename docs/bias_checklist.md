# Bias checklist: how each pitfall is handled

| Bias / failure | Mechanism in `nautilus_fi` | Where |
| --- | --- | --- |
| Latent implementation bias (signal and entry share a noisy print) | Decisions at 16:45 on published marks; fills only at the next 10:00 window; the execution reference is the **prior close** (or window-time quotes), never the fill-day close; TCA separates spread cost (vs reference) from delay drift (reference vs decision mid) without double counting | `MarketEnvironment.reference`, `execution.process.CostDecomposition`, `FixedIncomeLedger._process_new_fills` |
| Look-ahead (Enhanced TRACE sizes, revised vendor history, late CPI, full-sample filters) | Replay by `ts_init`; `public_size` capped until `size_revealed_ts`; evaluated prices ignored if published after the publish time; CPI used only after its publication date (projected otherwise, with status); `PointInTimeStore.read(as_of)` never overwrites snapshots; window liquidity statistics use prints disseminated before the window | `data.trace`, `data.pit_store`, `instruments.linkers.reference_cpi`, `daily_liquidity_stats(cutoff_time)` |
| Strategy reaches into the future | Strategies see only the `DecisionContext`; its `_publish` refuses data whose availability time is after now and `__getattr__` blocks env / ledger / engine / cache access | `core.context.DecisionContext` |
| Survivorship (universe from today's index / screen; dead bonds dropped) | `PointInTimeUniverse.members(date)` rebuilt from issuance / maturity / actions and PIT ratings; matured, called and defaulted bonds stay with final cashflows, claims and recoveries | `universe`, `MarketEnvironment.actions`, `accounting.ledger` |
| Stale-price smoothing | `STALE_ROLLED` marks move with duration x curve change + spread duration x bucket spread change + carry; evidence class per mark; share of market value by evidence class reported daily and in the bundle | `pricing.stale_roll`, `pricing.marks`, `result.evidence_table()` |
| Evaluated-price circularity | Mark tier, quality and lineage are on every mark; strategies can filter on quality; evidence shares show how much P&L sits on model / stale marks | `BondMark`, `MarkLineage`, `FixedIncomeResult.stats` |
| Bad TRACE prints | Dick-Nielsen style cancel / correction / reversal / duplicate filters plus median outlier filter | `data.trace.clean_trace` |
| Cost-free comparisons | Same strategy under GROSS, NET_SPREAD, NET_FULL; costs and fill probability depend on size, rating, duration, regime and protocol | `backtest.scenarios.run_execution_ladder`, `compare` |
| Phantom liquidity | A liquidity budget per bond per window shared across orders; fills capped against window-time volume; RFQ panel hit ratios; carry-forward and expiry of resting orders | `execution.process.LiquidityBudget`, `OrderProcessSimulator` |
| Spending unsettled cash | Spendable = settled cash less committed payables less reservations; the gate also subtracts what the window already offered; bridge financing only through an explicit policy | `funding.cash.CashView`, `FixedIncomeFillModel` |
| Silent funding failures | Daily funding assessment; breach ladder (hold buys, repo, liquidate by rule, declare failure); `economic_outcome = FUNDING_DEFAULT` recorded separately from `computational_status` | `FixedIncomeLedger._process_funding`, `core.manifest` |
| Catch-up coupons / coupons to same-day buyers | Entitlement crystallises on the first trade date whose settlement no longer carries the coupon (ex-date for gilt-style markets, record date where applicable), for the start-of-day holder; payment clears the receivable; negative accrued in ex periods | `FixedIncomeLedger._process_entitlements`, `instruments.conventions` |
| Anachronistic settlement | Dated settlement rules per market and asset type (US T+3 -> T+2 -> T+1 on 28 May 2024, Treasuries T+1, securitized T+3, loans T+7, EUR T+2, JGB T+2 -> T+1) | `instruments.conventions.SettlementConventions` |
| Unexplained NAV | Double-entry ledger with event lineage; `NAV = cash + dirty value + entitled coupons` asserted daily; conservation and payment reconciliation invariants; Nautilus cash reconciled to the ledger | `core.ledger`, `validation.invariants`, `result.reconciliation` |
| Overfitting | Walk-forward splits with purging, block bootstrap, Newey-West standard errors, deflated Sharpe, probability of backtest overfitting; manifests pin data hashes, seeds and assumptions so a result is reproducible | `research.walkforward`, `research.statistics`, `core.manifest` |
| Capacity | Fill size capped at a share of window volume, impact beyond typical size, capacity sweep at several AUM levels | `VolumeGatedLiquidityModel`, `ParametricCostModel`, `scenarios.run_capacity_sweep` |
| Regime dependence of costs | Stress index scales half spreads, impact and fill probability; cost stress multiplier | `costs`, `liquidity`, `scenarios.run_cost_stress` |
| Unsupported products quietly approximated | Support matrix with VALIDATED / SUPPORTED_WITH_APPROXIMATION / EXPERIMENTAL / UNSUPPORTED per family and feature; builder refuses above the allowed status; dependency validation before the run; the report bundle lists unknowns | `support.py`, `core.registry`, `backtest.builder` |
| Calibration drift | Calibration recipes with OK / STALE / FAILED status per date; stale curves beyond `max_stale_curve_days` are recorded and reported | `market.calibration`, `MarketEnvironment.curve_status` |
| Lag conventions differ between frameworks | `Timing.return_lag_days` is a named setting: a decision can never earn the return of its own information date (validated with an oracle signal), and evaluation forward windows start after the trade | `domain.conventions`, `paper.engine`, `paper.evaluate` |
| Silent zero-filled returns | `MissingReturnPolicy` (FAIL by default; ZERO, DROP_DATE, REFILL with a bad-date detector are explicit and counted); official records refuse zero-filled runs | `domain.conventions`, `governance.records` |
| Late vendor publication | evaluated prices and vendor analytics published after the mark time are used from the next trading day; field availability lags shift panels | `backtest.environment`, `data.panel` |
| New issues in benchmark reconstitutions | constituents not yet issued at the rebalance close are not buyable; benchmark weights renormalise over live members | `benchmarks`, `paper.engine` |
| Search counted as one trial | every run can record itself in the trial ledger; DSR uses the ledger's trial count and Sharpe variance; PBO uses the variant matrix; the holdout guard refuses re-use | `governance.ledger` |
| Irreproducible hashes | expiration orders get deterministic ids, so event-chain and output hashes reproduce across runs and streamed replay | `accounting.ledger` |
| Mixed annualisation inside one report | one `Annualisation` basis per run, printed with the statistics | `domain.conventions`, `backtest.result` |
